# Security policy

Nex Copilot acts in your browser with your accounts, so we treat security reports as urgent.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through a
[GitHub security advisory](https://github.com/AviOfLagos/nex-copilot/security/advisories/new).

Include what an attacker can do, the steps to reproduce, and the version (Settings › Help, or `manifest.json`).
We answer within three days, and credit you in the release notes unless you'd rather we didn't.

## What counts

Most valuable: anything that makes the extension send, post, buy, delete or change permissions without the user's
click (a gate bypass); a page, message or transcript that gets treated as an instruction (prompt injection); a key
or token leaving the vault; ambient audio or text leaving the computer; and a workspace's data reaching another.

## Supported versions

Only the latest release. Updating is re-running the install command; see the site's Install page.
